# Original design notes

`dean-prompts.md` is every prompt Dean sent while building the first version on base44, numbered and dated. `docs/RULES.md` cites these numbers (for example `#74`) for each rule in this build.

Later prompts changed earlier ones, and this rebuild returns to the horsepower, torque, weight and fuel model. Where the two disagree, `docs/RULES.md` and `src/game/balance.js` are what the game does today.
